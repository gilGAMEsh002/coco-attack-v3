## 1. 阶段目标与边界

建立不依赖真实模型调用的领域基座，能够读取既有资产、物化实验提示、清洗历史输出、调用既有静态 oracle 并生成指标与逐样本对拍报告。最终让后续生成与评估管线使用统一的数据、归属、版本和划分规则。

本阶段复用全部 9 个组合的静态 oracle，不另写一套判定器；当前记录中唯一列出的修改例外为 D05 所记用户批准的 cwe078-0 oracle v2 本体修复（[D05](./验收记录.md#d05)）。此例外不授权其他判定逻辑变更。数据校验、清洗、静态判定、指标计算和确定性划分独立于 DSPy；DSPy 仅作为独立应用包后续接入的依赖。本阶段不调用真实 API，不运行生成代码，不接入动态/真实性评估，也不实现功能测试结果缓存。

## 4. 公共接口与交付约定

- 以主方案的 `TaskRecord`、`ExperimentSpec`、`GenerationRecord`、`EvaluationRecord`、`MetricResult` 为公共记录边界；子任务 plan 再细化字段，避免各模块自行定义不兼容格式。
- 实验必须显式声明组合与 oracle 归属；历史素材导入通过显式映射补齐来源，运行期不按目录名或缺省值推断判定器。
- 静态 oracle 外层负责路由与返回值校验；本体以 D05 裁定后的 cwe078 v2 及其余 8 个原件为依据。记录源码版本/哈希，以共享参数化回归固化行为；版本号相同也不能代替源码哈希。
- 物化三件套时保存协议与提示版本。clean 不注入触发器；无 CoT 形态同时移除示例推理和要求生成 CoT 的 tail，其他内容变更须在差异报告中可见。
- cwe078 在排除示例后的 27 题上按 `sha256(seed:task_id)` 排序，seed=42，前 18 题为 search、后 9 题为 holdout，摘要相同时按 task_id 排序。其余组合不自动套用该比例；`whole-set` 是集合口径，不是第三种执行阶段。
- 生成失败显式映射为静态 `parse_error` 并留在分母；指标结果附分子、分母和未定义原因。pass@k 计算使用任务书估计量，本阶段仅使用构造的功能判定记录，不实际执行代码。
- 清洗按 D06 使用 cleaner-v3；历史对拍依 D03 比较布尔命中、集合与分母，不补造历史 verdict。依 D07 展示 AST 等价的外观差异，代码字段缺失明确不可比较（E02、§7.3），不把字段缺失算成代码一致。

阶段最终交付：可运行的领域基座、资产与版本清单、任务/提示快照、静态 oracle 接入、指标输出、参考校准和历史对拍报告。所有新产物进入显式输出目录。

## 5. 阶段统一测试与人工验收

按最新讨论采用阶段集中验收，替代“每个工作包各交一套测试”的组织方式。子任务只提出检查点；普通结构、文件包装不逐项补测试，公共规则集中复用少量参数化用例。

| 编号 | 验收组 | 通过标准与证据要求 |
|---|---|---|
| AC-01 | 数据、提示和划分 | 正常加载与缺测试/归属/示例互斥负例；同 seed 划分一致；三种 clean 集合一致；素材差异仅发生在允许区间。引用 E03 的集中检查及任务 01–03 过程证据 |
| AC-02 | 清洗与判定 | 四类输出清洗、9 组合校准、三重校验、失败不计 clean；按 D01、D05、D06 应用已批准边界与版本；新增差异不得自动豁免。引用 E01、E03、E05 |
| AC-03 | 指标边界 | 失败留分母、零分母与缺工具/judge 标未定义、n<k 与 pass@k 公式正确、baseline 错配拒绝。引用 E03，保留分子分母与配置来源 |
| AC-04 | 历史对拍 | 旧 4 组合代表 run 按 D03/D07 对拍；布尔/集合/分母精确一致或差异已裁定；外观差异和缺代码维度分别展示。完整范围引用 E02，E03/E04 的 2-run 检查不能替代它 |
| AC-05 | 差异、复现与人工审查 | 裁定、版本、运行范围、结果与产物可对应；已批准 oracle 修改与管线运行期间资产只读分开描述；遗留证据缺口显式列出，人工结论已填写。引用 E01–E06 及阶段验收审查项 |

以上编号仅统一引用现有标准及已记录裁定，不新增测试要求，不把本次编号日期视为标准最初制定日期。实际结果记录在验收记录，收尾对照在阶段验收；后续修改标准须说明依据与适用版本。

参考解用 `code_prompt + canonical_solution` 重组；已裁定例外从参考记录读取。裸函数体的实际可调用性留给阶段 02 的隔离执行验收，不能在本阶段裸执行生成代码。

过程证据和讨论写入[验收记录](./验收记录.md)，最终按 AC-01–AC-05 对照的摘要、限制与人工结论写入[阶段验收](./阶段验收.md)。不能为了通过验收擅自改写 oracle 或统计口径；已批准变更按 D 索引执行，新差异仍先整体汇报，由用户决定。
