## 1. 阶段目标与边界

建立不依赖真实模型调用的领域基座，能够读取既有资产、物化实验提示、清洗历史输出、调用既有静态 oracle 并生成指标与逐样本对拍报告。最终让后续生成与评估管线使用统一的数据、归属、版本和划分规则。

实现边界及已批准 oracle 例外遵循[数据与判定契约 B](../CoCo-Attack%20DSPy%20重建实施方案.md#domain-contract)。本阶段不调用真实 API，不运行生成代码，不接入动态/真实性评估，也不实现功能测试结果缓存。

## 2. 输入、依赖与已知问题

- 子任务 01 按[资产与来源 A](../CoCo-Attack%20DSPy%20重建实施方案.md#assets)核查仓库输入、实际 Python/DSPy 环境及评测依赖，交付机器可读清单；后续子任务从该清单读取路径和来源。
- 标准数据路由、示例选择记录、cwe078 的 31/30 差异及 cwe022 元数据的适用口径已同步至 A；原始资产核查和 D02/D04 裁定仍保留在本阶段[验收记录](./验收记录.md#decisions)。
- 子任务 03 读取[clean 提示契约 H](../CoCo-Attack%20DSPy%20重建实施方案.md#baseline-contract)准备素材，子任务 05 读取[参考校准与历史对拍 C](../CoCo-Attack%20DSPy%20重建实施方案.md#calibration)确定校准与对拍输入。

## 5. 阶段统一测试与人工验收

由子任务 05 汇集数据、提示、静态判定与指标检查，形成参考校准和历史对拍的集中验收材料。

| 编号  | 验收组               | 通过标准与证据要求                                                                                                                                             |
| ----- | -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| AC-01 | 数据、提示和划分     | 正常加载与缺测试/归属/示例互斥负例；同 seed 划分一致；三种 clean 集合一致；素材差异仅发生在允许区间。引用 E03 的集中检查及任务 01–03 过程证据                 |
| AC-02 | 清洗与判定           | 四类输出清洗、9 组合校准、三重校验、失败不计 clean；按 D01、D05、D06 应用已批准边界与版本；新增差异不得自动豁免。引用 E01、E03、E05                            |
| AC-03 | 指标边界             | 失败留分母、零分母与缺工具/judge 标未定义、n<k 与 pass@k 公式正确、baseline 错配拒绝。引用 E03，保留分子分母与配置来源                                         |
| AC-04 | 历史对拍             | 旧 4 组合代表 run 按 D03/D07 对拍；布尔/集合/分母精确一致或差异已裁定；外观差异和缺代码维度分别展示。完整范围引用 E02，E03/E04 的 2-run 检查不能替代它         |
| AC-05 | 差异、复现与人工审查 | 裁定、版本、运行范围、结果与产物可对应；已批准 oracle 修改与管线运行期间资产只读分开描述；遗留证据缺口显式列出，人工结论已填写。引用 E01–E06 及阶段验收审查项 |

参考解组装遵循[校准契约 C](../CoCo-Attack%20DSPy%20重建实施方案.md#calibration)；裸函数体的实际可调用性留给阶段 02 的隔离执行验收。
