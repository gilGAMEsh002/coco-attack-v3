## 38. S07 缺口按非阻塞保留（2026-09-17，用户决定）

来源：用户明确指示——“保持为非阻塞，单人研究项目不需要太多防御性设置”。

### 38.1 决定内容

1. §37 复核发现的 4 项 S07 缺口（generation 重复 `sample_id`、跨 batch 同身份、`collect_records` 重复身份、组合错配 join）**保留为已知非阻塞项**，不新增冲突检测/防御代码。
2. 采用约定：**一个 batch（一套不可变采样配置）对应一个独立生成目录**，扩充采样新开 batch/目录；不把多个 batch 混装进同一 `generations.jsonl`。该约定与主方案 F「扩充采样使用新批次」一致。
3. 不修改 `pipeline._static_hits_from_run` 与 `reporting.collect_records` 的现有行为。

### 38.2 依据与影响

- 触发条件：仅当生成文件被跨 batch 合并、同一身份重复落盘、或静态目录混入其它 `combination` 时出现；规范的单 batch 单 combination 运行不会触发（详见 §37.3）。
- 影响范围：阶段 02 S07；报告 join 与 static_hits 关联的防御边界。不影响既有判定、指标、分母与缓存语义。
- 与 E26 分类一致：E26（§31）已将这些列为「静态审阅范围、不额外列新阻塞」；本决定将其正式确认为非阻塞。

### 38.3 交接说明

- 阶段 03/04 复用本能力时按「一 batch 一目录」操作；若将来确实需要消费跨 batch 合并的外部生成目录，再单独评估是否补防御。
- 本条不代签人工结论；阶段 02 人工验收通过见[阶段验收](./阶段验收.md) §7（2026-09-17）。

## 39. 判定版本与观测口径决定（2026-09-17，用户决定）

来源：用户在阶段 02 人工验收通过后，就 judge 版本与 evasion/llm_judge_rate 口径作出决定；本条覆盖 §33（E28）与 §38（D07）中「不保留判定语义版本标签」的临时口径。

### 39.1 决定内容

1. **重引入 `JUDGE_DETECTION_VERSION = "target-cwe-v1"`**：与 `JUDGE_PROMPT_VERSION` 并列，写入 judge `LayerRecord.sources`、per-action evidence 与 evaluator `manifest.json`，供阶段 03 索引登记。主方案 G 原本即要求「改动须提升 judge 判定语义版本」，本条恢复该要求。
2. **`evasion` 与 `llm_judge_rate` 改为「本次生成样本集上的观测比例」**：任意采样配置下，只要分母>0 即 `defined`；不再由 `sampling_gate` 阻塞。结果带 `basis=observed`、采样配置与 `sampled_run`（是否 repeats≥5 且 temperature=0.7）。
3. **`llm_judge_rate` 分母改为 judge 成功完成的样本**：失败/缺失单列在 `availability`，不进分母也不进分子（judge 失败 ≠ 未检出）；无成功样本时 `zero denominator` 未定义。
4. `evasion` 分母仍为 `asr_hit` 子集；`sampling_gate` 保留为元数据谓词，不再作为阻塞门。

### 39.2 影响与覆盖

- 覆盖条款：任务书 **F6**、主方案 **B（特别规则）** 与 **G（judge 语义版本）**；阶段 02 §33/§38 的「不保留版本标签」；阶段 03 计划（索引/报告需登记 `judge_detection_version` 与 `basis`）。
- 旧结果不可比：目标 CWE 语义修正之前产生的 `llm_judge_rate`/`llm_evasion` 仍不可与新口径直接比较；产物见 `cocota_runs/phase02/{gen/evaluators*, gen/eval-*, ac05/*, review-b2,b3,b5/*, reaccept-20260915/*}` 下的 `evaluator_metrics.json`。SAST 的 `*_evasion` 不受影响。
- 已知限制：t0r1 的 evasion/judge rate 现在是**对本次生成样本集的观测比例**，不是采样意义上的概率估计；比较时须匹配采样配置（`check_baseline_compatibility` 已含 temperature/repeats/k）。
