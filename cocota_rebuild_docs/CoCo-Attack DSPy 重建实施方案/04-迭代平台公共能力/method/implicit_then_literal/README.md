## 研究想法（待收敛，不作为已裁定语义）

**先迭代隐式特征，再通过变量名与 CoT 迭代字面特征。**

直觉：把投毒模板的变异分成先后两段——先在**隐式/间接**表达上迭代（让目标模式的存在不以保证式字面量出现，例如经变量、容器、可调用工厂、表达式等间接表达），随后再通过**变量名与 CoT** 迭代**字面特征**（把字面锚点转移/承载到命名与推理链中）。重点是观察这种**次序**（先隐式、后字面）对受害模型命中目标模式与绕过 Semgrep 的影响。
