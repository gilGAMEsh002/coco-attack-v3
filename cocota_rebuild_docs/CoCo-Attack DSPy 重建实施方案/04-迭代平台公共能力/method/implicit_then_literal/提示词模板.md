# 角色提示词模板

作者：gpt · 2026-10-09

本方法将 A、B、乙的固定提示词从 Python 中抽出，作为随代码分发的 Markdown/Jinja2 模板。`roles.py` 准备上下文、检查输入预算、调用模型并解析响应；模板控制模型看到的角色说明、指令、段落顺序与输出格式示例。

## 编辑范围

提示词文件位于 `coco_attack/src/coco_attack/method/implicit_then_literal/prompt_templates/`。A 与 B 各有自己的 system/user 模板；乙共用一套归纳模板，归纳类别通过上下文传入。重复的经验和材料展示使用公共片段。

| 需要修改的内容 | 修改位置 |
| --- | --- |
| A 的角色说明、任务要求、输出示例 | `prompt_templates/a/` |
| B 的角色说明、任务要求、输出示例 | `prompt_templates/b/` |
| 乙的归纳要求、证据说明、输出示例 | `prompt_templates/inducer/` |
| 两类经验、任务材料等公共展示 | `prompt_templates/shared/` |
| 输入字段准备、预算、响应解析 | `roles.py` |
| 模板加载、严格渲染、内容身份 | `prompt_renderer.py` |

victim 使用的 few-shot 代码、CoT 和任务指令仍由 `TemplateSnapshot` 与公共提示物化服务管理。它们是被研究方法修改的实验资产，不与 A/B/乙的角色提示词混放。

## 编辑约定

- 模板使用 `{{ variable }}` 插入上下文，用 `{% ... %}` 控制布局。普通 JSON 的花括号不需要像 Python `str.format` 那样转义。
- `manifest.json` 管理逻辑入口到文件路径的映射；重命名文件时同步更新映射，修改措辞不需要改 Python。
- 上下文中的代码、JSON、经验摘要只作为文本插入，不作第二次模板渲染；其中出现 `{{ ... }}` 时原样保留。
- 缺少模板或必需变量应在模型调用前报错，不降级为空提示词。文本提示词不使用 HTML 转义。
- 输出格式示例帮助模型理解协议；真实字段约束、证据引用和修改合法性仍由 Python 校验。若改变 JSON 协议，必须同步修改解析器、协议版本和相应测试。
- 本次重构保持完整 system/user 文本及输入 token 估算与抽取前一致。后续措辞优化应作为独立变更验证，不能把结构重构与效果变化混在同次实验中。

实际发给模型的完整消息仍由角色动作存储保留；阅读模板文件可以了解指令结构，复核某次实验应查看该动作落盘的消息与经验输入。

## 版本与恢复

`manifest.json` 声明模板入口，内容指纹覆盖该文件和全部模板文件的相对路径与原始内容。新配置的 `prompt_template_sha256` 参与运行身份；首次运行把完整模板集保存为 run 目录中的 `prompt_bundle.json`，后续恢复读取并验证这个副本。因此，编辑工作区模板影响新实验，不会在既有新格式 run 中途替换指令。要验证修改后的提示词，应使用新的 run 目录。

一次运行或独立角色组装使用同一个内存模板集，避免多个片段分次读取到不同版本。乙的逻辑输入锁与归纳提交记录也固定模板指纹，显式重试和已提交经验的恢复都要核对，不能通过复用提交绕过版本检查。

抽取前的旧 run 不自动迁移：保留原配置身份，仅允许使用本次逐字等价验证的原始模板集继续；若工作区模板已改变，旧 run 会在修改状态或调用模型前阻塞。旧动作请求也保留原请求身份，不因补充模板元数据而重复调用。读取旧运行状态不依赖当前工作区模板内容。

## 离线验证

```bash
cd coco_attack
.venv/bin/python -m pytest -q \
  tests/test_implicit_then_literal_prompt_templates.py \
  tests/test_implicit_then_literal_prompt_recovery.py \
  tests/test_implicit_then_literal_roles.py \
  tests/test_implicit_then_literal_experience.py
```

模板等价测试使用抽取前固定的 66 组完整消息摘要和 token 估算，不从新模板反向生成期望值；覆盖空/双类经验、材料与目标列表、失败概要以及包含 Jinja 语法外观的动态文本。恢复测试另覆盖模板副本、篡改、旧配置身份和旧 A/B/乙动作复用。

有意调整提示词后，原始等价测试应报告差异；审核这些差异后再更新对应测试期望，并记录模板变更。`LEGACY_TEMPLATE_SHA256` 是兼容旧实验的固定边界，不应随新措辞更新，否则会错误地把新提示词当作旧实验版本。
