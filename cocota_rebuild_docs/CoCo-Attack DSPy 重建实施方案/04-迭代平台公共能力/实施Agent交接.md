## 共同边界

- 保留工作区其他协作者的修改，不回退已有实现。公共服务不内置方法策略。
- 不修改 oracle、指标、缓存或数据划分来使候选过门；基线身份与比较条件明确。
- 原始资产和历史产物不改写；改模型/协议等研究配置须遵循现有身份规则，不伪装原 run 恢复。
- 运行/恢复/重试会产生真实动作；只读状态与报告不会。停止点已到达后再次恢复可能推进下一轮。
- 未知请求、协议错误、容量不足和工具故障如实报告；按用户范围处置，不能以 mock 代替真实证据。
- 新增记录标注真实作者。gpt 整理/复核署 gpt；deepseek、kimi 等实施记录保留其作者，不覆盖历史归属。
