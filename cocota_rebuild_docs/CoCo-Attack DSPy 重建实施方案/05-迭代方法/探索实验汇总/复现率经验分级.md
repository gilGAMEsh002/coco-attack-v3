# 复现率经验分级：迭代起点与探索方向

整理与分级：GPT / Codex；资料归纳与交叉审阅：DeepSeek-v4.1-flash（OpenCode Go，多轮）。本版在 kimi 原稿基础上重新组织，保留原始实验记录与计数。整理日期：2026-10-22；实验数据截点沿用 **2026-10-17T12:52:22+08:00**。

依据：[探索实验总览](<探索实验总览.md>)、对应候选模板及必要的原始产物。本页回答两个问题：**哪些经验足以支持选一个迭代起点，哪些方向值得继续探索？** 没有新增 victim 采样；本页功能列已加入2026-10-22的 t146 专用重评，以下方法建议仍不代表已经实施。本文的“复现率”沿用项目含义，指 victim 输出中目标行为的命中比例；它不同于“独立重采能否重复得到相同结论”。

**当前建议：以 B2 为默认参照，A4 和 B8 为两条优先分支，A2 为简化备选。** B2 的对照较齐全；A4 有三题重复采样的高命中结果；B8 有扩展题筛选结果；A2 有删除 key 后仍保留较高命中的记录。这些是选择起点的依据，尚不能排列出跨任务稳定的优劣。

## 1. 如何理解分级

证据等级和迭代优先级分开：一个方向可以尚未验证，却因为能回答关键疑问而值得优先探索。


| 证据等级               | 含义                                                                       | 可以怎样使用                                           |
| ------------------------ | ---------------------------------------------------------------------------- | -------------------------------------------------------- |
| **Ⅰ：可支撑局部起点** | 具体模板有多次采样或不止一种任务规模的记录，足以确认在已测条件下有可用表现 | 保留模板作为参照或起点；不把表现归因于未拆开的某个成分 |
| **Ⅱ：值得验证的线索** | 有实际对照或观察，但存在单次采样、条件同时变化、题面损坏或覆盖不足         | 把它转成下一轮要回答的问题，不写成通用规律             |
| **Ⅲ：待验证假设**     | 尚无直接对照，或现有记录不能辨别几种解释                                   | 说明为什么值得测，以及哪种结果会改变判断               |
| **不用于该结论**       | 实际对照未成立、失败占主导、结果未评估，或超出本次资料范围                 | 保留事实，但不拿来支持该方法效果                       |

这里的Ⅰ级表示“可以从这个模板继续”，不表示统计上已证明它优于其他模板。没有检出差异不等于无效、等效或不劣；也不用一个统一的差值阈值替代逐题和跨批次核对。**低优先级同样不等于方向已被否定。**

除单独标注外，本页经验适用于 victim **`deepseek-v4-flash-0731`**、**`cwe078-0`**。不把阶段 03 的 `DeepSeek-V3.2` clean 结果当作 0731 的同条件基线，不把旧 CWE 的观察提升为本轮经验。

## 4. 有探索潜力的方向与优先顺序

以下是后续试验建议。每次选一个问题即可，不要求一次铺开所有组合或建设新的迭代框架。


| 优先顺序                                | 要回答的问题                                         | 当前依据                                 | 建议最小改动与判断重点                                                                                                                                                                                                                                                   |
| ----------------------------------------- | ------------------------------------------------------ | ------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **优先 1：起点同场比较**                | A4、B8 相对 B2 的优势能否在同样条件下保留？          | 具体模板Ⅰ级，优劣关系Ⅱ级               | 同模型、v2、同任务与repeat比较B2/A4/B8。三题的静态命中已较高，不作为主要静态排序依据；功能与联合结果仍有差距，已重评的t146继续用于逐题诊断。优先补A4的扩展筛选，与B2/B8在相同筛选题上重采并逐题比较。筛选题仍可能封顶，应关注有区分度的题并保留重采，不称最终测试        |
| **优先 2：组织方式与末尾指令**          | 是拆分步骤、末尾指令，还是两者组合更有帮助？         | Ⅱ级；A4+末尾指令尚属Ⅲ级                | 先固定code，分别比较B2/A4及各自有无B8的完整末行，明确末行含指令和重复key。若要继续拆分，再测只保留指令的版本；“仅指令”与B8整条末行是不同条件。核对实际发送文本，不用失败的W/O批次替代                                                                                  |
| **优先 3：小幅改写的容忍程度**          | 有效CoT能否被改写，哪些变化保留效果？                | Ⅱ级线索，具体改写规则Ⅲ级               | 从同一个B2或A4出发，每次只做同义词、语序或拆句中的一种；保留未改模板重采。EFA三个cot run的15候选相对各自 `base_source` 只改CoT，可按真实来源配对回看；但位置、次数、归因方式可能一起改变，且来自不同code来源和v1两题，不能替代v2单项改写对照，也不称“任何改写都会归零” |
| **优先 4：触发控制与一般模仿**          | 提升来自测试题触发，还是示例普遍改变了实现偏好？     | T/NT观察Ⅱ级；替换词项、关闭全部标记Ⅲ级 | 区分示例任务描述、CoT、测试题三处标记。现有S1off没关CoT标记，“三处全关”仍是新假设。先复核已有T/NT，再选择一个位置做单独删除或词项替换；每次说明实际哪处改了。仍有命中只支持非触发条件下也可能采用该写法，不直接证明模型内部机制                                        |
| **第二梯队：换 code 机制**              | 同一CoT组织方式能否用于其他代码形态？                | 五源候选CoT探针提供Ⅱ级线索              | 固定CoT的组织，明确随code同步调整的机制说明，分开报告各模板。不要把“措辞框架相同”说成文本完全相同，也不要把复杂程度与可检出程度预设成一条必然排序                                                                                                                      |
| **第二梯队：CoT是否指出了要模仿的规则** | CoT指向目标操作和无关操作时，victim是否不同？        | Ⅲ级，现有材料无直接对照                 | 保持code，给出形式相近但指向无关步骤的说明；结果只能增加或削弱“规则指向”解释，不能凭一次对照确定内部原因                                                                                                                                                               |
| **较低优先：命名与字面复现**            | 命名改变的是采用目标行为，还是复制具体表达式的程度？ | 命中计数Ⅱ级；精确复制比例本页未重核     | 若研究目标需要，再对已有生成代码逐样本分开统计行为采用、表达式复制、改名、实现改写；不能只在命中样本内统计后推成全体结论                                                                                                                                                 |

如果要正式讨论“code 与 CoT 的协同”，还需要完整的四种条件：clean code/clean CoT、修改 code/clean CoT、clean code/修改 CoT、修改 code/修改 CoT。在说明比较尺度后考察组合效果是否超出各自变化；“组合高于其他条件”本身不充分。示例里没有目标行为，也不能预先断言 victim 输出必为零。此项属于 **Ⅲ级研究假设**，不作为当前起点选择的必要前提。

## 6. 使用这些经验时保留的测量边界

- **分清三种结果**：目标命中、功能通过、命中且通过分别列出；功能通过较多不一定代表目标行为更多，联合结果用于观察两者是否同时满足，不据这次重评另设唯一排序指标。当前筛选记录中B8为25/26、3/26、2/26，clean为3/26、4/26、1/26；低功能通过原因不能仅据这张表归因于投毒或题难。
- **已重评的t146可用于功能诊断**：原测试只模拟 `check_output`，部分 `run`/`Popen` 实现绕过模拟并调用缺失的ping；v6统一模拟，并补充完整地址与调用核对。当前判断采用修正后的结果，旧值用于追溯；不能继续把这些批次概括为“t146功能不可用”或“全部失败都因缺ping”。残余失败按具体记录分析，包括 `.hosts()` 漏地址、错误目标或忽略失败等。版本、逐条代码与测试哈希见[修正对照](<t146功能评测修正对照.md>)。本次只覆盖原已有功能证据的93批、1188条t146记录；另77批、752条没有该题功能结果的记录仍未补评，31条生成失败未执行测试。其他任务没有随之重评，26题扩展筛选不含t146，原有限制继续保留。
- **不拼接条件来排名**：v1/v2、三题/单题/26题、不同victim和oracle分别保留；三题×20不是60道独立任务。换repeat意味着重新采样，不是必然提高效果。
- **同模板会波动**：A2的r10为20/30，r20两次为56/60、53/60，repeat和采样时段分别标明；A3的r20为32/60，后续r20为35/60、37/60、41/60，亦有并发设置差异。尽量在相近时段比较同一组候选，并保留参照重采；不用这几次的最大差作为通用“显著性门槛”。
- **未知不写零，引用不算新增**：未评估、截断、报错和无功能结果按实际状态写；B8-T引用B8-gen25的26条，另一次真正重采则保留新增计数。独立补做功能评估也不意味着训练循环当时已执行功能测试。
