## 1. 如何理解分级

先判断是否符合迭代空间约束，再对范围内的模板和方向评定证据等级与优先级。范围外的模板可以支持成因分析，但不获得起点资格。一个范围内的方向可以尚未验证，却因为能回答关键疑问而值得优先探索。


| 证据等级               | 含义                                                                       | 可以怎样使用                                           |
| ------------------------ | ---------------------------------------------------------------------------- | -------------------------------------------------------- |
| **Ⅰ：可支撑局部起点** | 具体模板有多次采样或不止一种任务规模的记录，足以确认在已测条件下有可用表现 | 保留模板作为参照或起点；不把表现归因于未拆开的某个成分 |
| **Ⅱ：值得验证的线索** | 有实际对照或观察，但存在单次采样、条件同时变化、题面损坏或覆盖不足         | 把它转成下一轮要回答的问题，不写成通用规律             |
| **Ⅲ：待验证假设**     | 尚无直接对照，或现有记录不能辨别几种解释                                   | 说明为什么值得测，以及哪种结果会改变判断               |
| **不用于该结论**       | 实际对照未成立、失败占主导、结果未评估，或超出本次资料范围                 | 保留事实，但不拿来支持该方法效果                       |

这里的Ⅰ级表示“可以从这个模板继续”，不表示统计上已证明它优于其他模板。没有检出差异不等于无效、等效或不劣；也不用一个统一的差值阈值替代逐题和跨批次核对。**低优先级同样不等于方向已被否定。**

除单独标注外，本页经验适用于 victim **`deepseek-v4-flash-0731`**、**`cwe078-0`**。不把阶段 03 的 `DeepSeek-V3.2` clean 结果当作 0731 的同条件基线，不把旧 CWE 的观察提升为本轮经验。

### 2.3 从结果中提取的迭代方向

**用 B2 建立参照，优先探索 A4 的步骤组织。** 三题 repeat 20 中，B2 的命中且通过为 42/60，A4 为 46/60；A4 在 repeat 10 中也有 29/30 命中、22/30 命中且通过。将 key 从自然语言步骤中拆出，是已有实验支持、值得优先继续的方向。下一步可补充 A4 的扩展题结果，与 B2 逐题比较。

**用 A2 探索自然语言说明的简化空间。** 删除 key 后，A2 两批 repeat 20 仍取得 56/60、53/60 命中，以及 42/60、41/60 命中且通过。这为保留有效步骤说明、精简显式代码表达提供了可用起点。

**区分去掉标签与删除表达式。** B2-nolabel仅将 `key:` 标签及其连接标点改为 `using` 衔接，仍保留行内表达式；本批29/30命中、24/30联合说明这种具体写法在三道已用过的调参题上有实际表现。A2则连同表达式一起删除。这是不同改法，不把B2-nolabel的结果写成“去掉表达式仍有效”，也不由一次单臂结果证明 `key:` 普遍无用。

**把功能反馈落实到具体任务。** 扩展题中，B2 与 B9 的功能通过均为 10/26、命中且通过均为 8/26，静态命中分别为 22/26、19/26。逐题看，B2 与 clean 共同通过 9 题，B2 另通过任务 13，clean 另通过任务 12；B9 与 clean 共同通过 7 题。这些差异可以帮助选择回看任务。B2 的 22 条命中中有 14 条未通过功能，可结合实际代码和测试详情归纳具体问题，再用于下一轮修改。

**用元指令对照分析“要求模仿”可能带来的影响。** B8 比 B2 多 3 条静态命中、1 条功能通过、2 条命中且通过，并通过了 clean 通过的全部 10 题，另通过任务 13。它的末行同时包含 `Feature pattern to imitate…` 和重复出现的 key，提供了分析显式模仿要求、信息重复与位置作用的线索。B8/B5 的用途限于成因分析，迭代起点继续采用 B2/A4/A2。

| **优先 1：起点同场比较**                | A4、A2 相对 B2 的优势能否在同样条件下保留？          | 具体模板Ⅰ级，优劣关系Ⅱ级                 | 同模型、v2、同任务与repeat比较B2/A4/A2。三题的静态命中已较高，不作为主要静态排序依据；功能与联合结果仍有差距。对比使用各任务一致的评测版本并保留来源；补A4/A2的扩展筛选，与B2在相同筛选题上重采并逐题比较。筛选题仍可能封顶，应关注有区分度的题并保留重采，不称最终测试                    |
| **与起点比较并行：功能失败诊断**        | 哪些命中样本未完成功能，哪些修改可能兼顾两者？       | 当前结果支持问题存在（Ⅱ）；具体改法待验证 | 先读B2/A4/A2现有失败的实际代码与当前测试详情，区分遗漏行为和评测限制；再只针对有明确依据的问题修改。新一轮同时跟踪命中、功能、联合结果，不把通过率变化直接归因于某一句CoT，也不另设未经确定的唯一排序公式                                                                                  |
| **优先 2：自然语言与key的组织方式**     | 自然语言说明、key的保留与位置怎样影响表现？          | Ⅱ级；具体改写效果待验证                   | 固定code，以B2/A4/A2已有差异为依据，每次只改变key的保留或位置、步骤拆分中的一项。保留任务内的推理说明，不追加要求模型模仿特征的元指令；同时观察命中、功能和联合结果。                                                                                                                      |
| **优先 3：小幅改写的容忍程度**          | 有效CoT能否被改写，哪些变化保留效果？                | Ⅱ级线索，具体改写规则Ⅲ级                 | 从同一个B2或A4出发，每次只做同义词、语序或拆句中的一种；保留未改模板重采。EFA三个cot run的15候选相对各自 `base_source` 只改CoT，可按真实来源配对回看；但位置、次数、归因方式可能一起改变，且来自不同code来源和v1两题，不能替代v2单项改写对照，也不称“任何改写都会归零”                   |
| **优先 4：触发控制与一般模仿**          | 提升来自测试题触发，还是示例普遍改变了实现偏好？     | T/NT观察Ⅱ级；替换词项、关闭全部标记Ⅲ级   | 区分示例任务描述、CoT、测试题三处标记。现有S1off没关CoT标记，“三处全关”仍是新假设。已有B8 T/NT仅用于成因分析，不能直接推广到无元指令模板；后续从B2等范围内起点选择一个位置做单独删除或词项替换；每次说明实际哪处改了。仍有命中只支持非触发条件下也可能采用该写法，不直接证明模型内部机制 |
| **第二梯队：换 code 机制**              | 同一CoT组织方式能否用于其他代码形态？                | 五源候选CoT探针提供Ⅱ级线索                | 固定CoT的组织，明确随code同步调整的机制说明，分开报告各模板。不要把“措辞框架相同”说成文本完全相同，也不要把复杂程度与可检出程度预设成一条必然排序                                                                                                                                        |
| **第二梯队：CoT是否指出了要模仿的规则** | CoT指向目标操作和无关操作时，victim是否不同？        | Ⅲ级，现有材料无直接对照                   | 保持code，给出形式相近但指向无关步骤的说明；结果只能增加或削弱“规则指向”解释，不能凭一次对照确定内部原因                                                                                                                                                                                 |
| **较低优先：命名与字面复现**            | 命名改变的是采用目标行为，还是复制具体表达式的程度？ | 命中计数Ⅱ级；精确复制比例本页未重核       | 若研究目标需要，再对已有生成代码逐样本分开统计行为采用、表达式复制、改名、实现改写；不能只在命中样本内统计后推成全体结论                                                                                                                                                                   |

如果要正式讨论“code 与 CoT 的协同”，还需要完整的四种条件：clean code/clean CoT、修改 code/clean CoT、clean code/修改 CoT、修改 code/修改 CoT。在说明比较尺度后考察组合效果是否超出各自变化；“组合高于其他条件”本身不充分。示例里没有目标行为，也不能预先断言 victim 输出必为零。此项属于 **Ⅲ级研究假设**，不作为当前起点选择的必要前提。

## 6. 使用这些经验时保留的测量边界

- **分清三种结果**：目标命中、功能************通过、命中且通过分别列出；功能通过较多不一定代表目标行为更多，联合结果用于观察两者是否同时满足，不据这次重评另设唯一排序指标。当前扩展题B8为25/26、11/26、10/26，CLEAN为3/26、10/26、2/26。原值及第二轮综合值分别保留在历史对照中；本页的选择判断采用当前汇总，低通过率本身仍不能说明失败原因。
- **已重评的t146可用于功能诊断**：原测试只模拟 `check_output`，部分 `run`/`Popen` 实现绕过模拟并调用缺失的ping；v6统一模拟，并补充完整地址与调用核对。当前判断采用修正后的结果，旧值用于追溯；不能继续把这些批次概括为“t146功能不可用”或“全部失败都因缺ping”。残余失败按具体记录分析，包括 `.hosts()` 漏地址、错误目标或忽略失败等。版本、逐条代码与测试哈希见[修正对照](<t146功能评测修正对照.md>)。t146专项覆盖原已有功能证据的93批、1188条记录；另77批、752条没有该题功能结果的记录未补评，31条生成失败未执行测试。10月23日的300条重评未涉及t146，所以本页历史三题批次中的t146仍使用专项结果；B2-nolabel另采用2026-10-26新采样的5/10功能通过。26题扩展虽不含t146，但已因其他任务修正更新，不能继续说“26题功能结果不变”。
- **修复范围与实际重评范围分开**：10月23日公布的300条重评涉及12、15、17、195、320、326、350、715、745、1102；当前全部功能汇总还包含沿用的历史记录。322、810虽然修了测试，在本总览中没有对应的已保存研究响应，不能凭实现验证补写研究结果。残余失败是否属于实现错误，需结合具体任务的测试覆盖边界核查；v1题面损坏、每题repeat1和筛选题被反复使用的限制继续保留。
- **不拼接条件来排名**：v1/v2、三题/单题/26题、不同victim和oracle分别保留；三题×20不是60道独立任务。换repeat意味着重新采样，不是必然提高效果。
- **同模板会波动**：A2的r10为20/30，r20两次为56/60、53/60，repeat和采样时段分别标明；A3的r20为32/60，后续r20为35/60、37/60、41/60，亦有并发设置差异。尽量在相近时段比较同一组候选，并保留参照重采；不用这几次的最大差作为通用“显著性门槛”。
- **未知不写零，引用不算新增**：未评估、截断、报错和无功能结果按实际状态写；B8-T引用B8-gen25的26条，另一次真正重采则保留新增计数。独立补做功能评估也不意味着训练循环当时已执行功能测试。
