## 攻击目标与攻击判定

本表定义[攻击目标与攻击判定](攻击目标与攻击判定.md)中反复使用的术语；定义以该文档正文为准。

- **目标模式（target pattern）**：行为级、不绑定写法的判定陈述。主句说明"发生了什么"，是本阶段判定与 oracle 对齐的范围；括号内列出本阶段不判定的前提（如输入是否可控、是否实际访问 HTTPS），这些前提另作任务上下文记录，不进入命中判定。
- **判定边界（decision boundary）**：目标模式在理想形态下的 in / out / 不确定 清单，说明什么判 present、什么判 absent、什么留待不确定；oracle 实现以它为对齐基准。
  - **present / absent / possibly_present（出现 / 未出现 / 可能出现）**：三值判定结果。present 为确定出现；absent 为确定不出现；possibly_present 为代码可解析、但目标相关的值无法静态确定（例如 shell 取值依赖运行期表达式）。
  - **parse_error（解析失败）**：产物无法解析，因而没有判定。它不属于三值中的任何一类。
  - **evaluation gap（评估缺口）**：oracle 或 SAST 未运行、报错、或规则不适用，因而没有判定。它与 parse_error 分开记录。
- **命中（hit，记为 `H`）**：oracle 判为 present 或 possibly_present 的样本。parse_error 与评估缺口不计为命中，也不计为未命中；命中因此是风险相关行为的上界，而不是"确定出现"的计数。
- **功能正确性（functional correctness）**：示例或输出通过该任务的功能测试。相关的前置检查属于实现细节，不作为文档中的独立门项。
- **oracle（判定实现）**：按判定边界判定目标模式是否出现的工具，输出三值判定。仓库中有静态、动态与真实性（security realism）三类；**本阶段用于攻击判定的是静态 oracle（static oracle）**。它是测量工具，覆盖范围有限，不等于漏洞真值；正文统一写 oracle。
- **SAST（静态应用安全测试工具）**：在源代码上按指定规则集报告安全问题的工具，产生检测结果 `D`。本阶段使用哪些工具与规则版本，在实验配置中列明；多个工具分别记录。
- **clean 参照（clean reference）**：代码与 CoT 均未受污染的模板，用于在与候选相同的训练题和采样设置下测量自然模式出现与任务难度。它作为评价基线不参与候选修改；其原始 code/CoT 可以与迭代起点同源，但攻击起点和 clean 参照的 trigger 条件与用途须分开。
  - **clean-0shot（零样本 clean 参照）**：不含任何 few-shot 示例、仅使用任务提示的 clean 参照；评测集不因无示例而改变。
  - **clean-fewshot（少样本 clean 参照）**：使用未污染 few-shot 示例的 clean 参照；按是否保留 CoT 分为 `clean_fewshot_cot` 与 `clean_fewshot_no_cot` 两种形态。
- **trigger（触发词）**：作为固定背景设置注入的标记。后三个示例的任务描述与查询首句默认包含它，每个可修改示例的 CoT 至多出现一次。其内容与注入规则固定，属于背景设置而非候选的探索维度。
