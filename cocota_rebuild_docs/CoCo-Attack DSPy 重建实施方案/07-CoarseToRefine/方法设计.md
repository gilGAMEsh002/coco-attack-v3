# CoarseToRefine 方法设计

研究选择：用户；设计整理：GPT / Codex，2026-10-28。

状态：待实现的方法设计，尚未新增模型调用或实验。本方法独立于 evidence_guided_search，不继承它的 guided/unguided/probe、经验检验调度、模型配置、预算数、选择规则或实验结果。公共目标、修改范围、输入与保存、数据划分和评价口径遵循[统一实验协议](../06-统一实验协议/统一实验协议.md)。

## 1. 方法目的与对象

先探索代码实现结构及其配套 CoT，再针对粗模板的具体问题定向精修。每份模板都是可直接物化的完整四示例对象，只有示例2–4的 code/CoT 可改。原始 clean few-shot 起点与不注入 trigger 的 clean 评价参照分开记录；B2-nolabel 是旧方法固定任务演示，不能成为本方法的默认父模板或已验证模式。

用户已确认的设计包括：经验按 cot/code/both 组织并分为人工审核的一级稳定经验与迭代提出的二级经验；粗生成只读取合并后的一级经验；新增精修方向安排角色；精修复用候选生成模型，按指定方向读取经验；独立归纳后统一汇总。经验的具体组织见[经验组织与更新](经验组织与更新.md)。

## 2. 四个角色职责、五种调用

| 角色 | 调用与输入 | 输出 |
| --- | --- | --- |
| 候选生成 | 粗生成：固定起点、允许的示例/测试与目标规则、合并后的一级稳定经验、已探索 code 关键形态记录 | 完整可物化粗模板，期望 victim 学习的具体模式，code 关键形态 |
| 精修方向安排 | 粗模板、预期模式及已取得的真实检查/测量证据；无证据时明确仅基于模板判断 | 为粗模板指定 cot、code 或 both，说明理由及希望解决的问题 |
| 候选生成（复用同一模型） | 定向精修：粗模板、方向与理由、指定方向及 both 的一级与有关二级经验 | 完整精修模板、改动说明与预期变化；未指定侧字段不可改 |
| 独立归纳 | 读取分配给该次归纳的模板、实际训练题、测试、victim 输出与评价；归纳单位与跨臂可见范围待定 | 引用程序计算的真实计数、模式采用情况、功能与检测变化、不确定性及二级经验提案 |
| 统一汇总 | 本轮独立报告及其证据引用 | 汇总和修订二级经验，保留支持、反例与未知；供人工审核参考 |

表中候选生成有粗生成与精修两种调用，因此是四个角色职责、五种调用类型，不是五个独立角色。这里仅定义职责，具体提示词、调用次数、数据结构与接线待实现。

方向为 cot 时冻结 code；为 code 时冻结 cot；为 both 时两侧可改。程序应检查未指定侧及公共固定字段保持不变。若需要连带修改另一侧，应重新安排 both，不能由精修调用自行扩大范围。方向安排使用何种模型、精确反馈范围及每粗模板的精修分支数待定，不能据此默认该角色可读取所有原始输出。交给精修模型的方向理由遵守共同信息边界：可提供摘要、聚合计数、适用条件与逻辑证据编号，不得转发训练题/测试原文、参考实现、逐样本 victim 代码或响应，以及可读取原始输出的文件路径。理由若含 victim 反馈，须披露其来源为训练反馈；合法的逐题聚合计数不因按题组织而被排除。

## 3. 一轮的逻辑过程

从固定起点粗生成，记录每份 code 关键形态和预期学习模式；物化并执行示例检查。方向安排为粗模板提出 cot/code/both 及理由，生成模型据此定向精修。粗、精模板分别保存各自实际取得的检查/测量及未测原因；是否、何时进行配对测量仍待确认。随后独立归纳（单模板或配对作为归纳单位及跨臂可见范围待定），在轮末统一汇总为二级经验，结束本轮。

同轮精修读取冻结的轮初二级经验版本；本轮提案经统一汇总后供下一轮读取，不逐候选滚动更新。二级不得自动改写人工审核的一级，冲突须保留并供人工审核，具体采用与处理规则待定。

上述是职责顺序，不指定调用次数与全部调度细节。粗模板何时测量、未准入模板是否允许示例侧修复、精修次数与分支、失败后是否继续均待定。没有 victim 测量时只能基于示例提出精修理由，不能宣称已有 victim 效果证据。

每轮记录 code 的目标操作、具体表示、数据依赖、控制流程、程序组织及与已有结构的关系，后续粗生成避免重复探索相同关键结构。关键形态记录只用于覆盖与去重导航，不向粗生成注入二级效果结论。具体“同结构”判断粒度待定。该限制只针对新的粗探索：cot 精修、配对对照和复测允许同 code，不能因代码重复丢弃这些必要记录。

## 4. 效果解释与证据要求

预期 victim 学习的具体模式是候选假设，用于观察其是否被采用；它不能改写[原始目标定义与 H/D/F](../06-统一实验协议/攻击目标与攻击判定.md)。记录预期与实际输出的对应，同时报告功能、模式命中、SAST 及缺口。

建议粗模板和对应精模板在可比的训练题、victim、采样、trigger 与评价条件下都测量，才能判断精修前后的 victim 效果增减；此项配对测量安排尚待确认。缺少粗模板基线时，只报告精后表现或示例可行性，不构造增益。单次差异保留真实分母与随机波动，不解释成某类改动普遍有效的因果结论。

最终选择规则、功能约束、复测安排、模型配置、预算数与停止条件待定。公共数据安排继续适用；最终测试不进入本次经验更新。新方法未来结果必须对应自己的配置、模板和原始 run，不能引用旧方法试跑作为本方法成效。
